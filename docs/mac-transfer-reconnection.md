# Mac連携の自動再接続

アプリがフォアグラウンドにある間、Network.frameworkの経路監視でWi-Fi・モバイル通信・VPNの経路変更を検出する。変更時は1秒待って検出と接続をやり直し、古いBonjourの接続先と受信途中のバッファを破棄する。保存済みログと未完了の受信確認は保持する。

通常はBonjourで通知されたLANのアドレスを使う。Bonjourが見つからない場合も、ペアリングに保存されたTailscaleのアドレスへ直接接続する。失敗した場合は5、10、20、40、60秒と間隔を空けて再試行し、正常受信後は60秒間隔で新着を確認する。古い接続のコールバックは現在の受信処理へ反映しない。

すべてのウインドウがバックグラウンドへ移ったら監視と再試行を停止する。アプリが再びアクティブになると自動再開する。「Macを再検索」は任意の手動操作であり、通常の取り込みに必要としない。アプリが終了・停止している間の常時バックグラウンド受信を保証するものではない。

## 検証状況（2026-09-26）

- 自動再接続追加前に、iPhone 17からMacのTailscale IPへの認証付き接続と暗号化された応答の受信を確認。
- iPadの受信済みログの復旧・記録への取り込みを確認。USBを外した状態での一連の再接続試験は未完了。
- 自動再接続を追加した実機向けDebugビルドは成功。Wi-Fiからモバイル通信への切り替え後、手動の再検索なしで接続する実機試験は更新インストール待ち。
