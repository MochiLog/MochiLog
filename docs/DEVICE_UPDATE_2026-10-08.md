# 実機更新（2026-10-08）

開発者向けの更新記録。記録データ・ペアリング・設定は削除せず、既存アプリへ上書きした。

| 対象 | 更新した版 | 確認 |
| --- | --- | --- |
| iPhone 17 | 4.0.0 (1033) | devicectlのインストール・起動成功、インストール済みバージョン照合 |
| iPad Pro 13-inch M4 | 4.0.0 (1033) | devicectlのインストール・起動成功、インストール済みバージョン照合 |
| MochiLog Mac | 0.2.14 (17) | 公証済み配布物を上書き、署名・Gatekeeper検証成功、プロセス起動確認 |
| MochiLog Windows | 0.1.11 | インストーラー終了コード0、ファイルバージョン照合、ユーザーのデスクトップセッションで起動確認 |
| Mac上のiPhone/iPad版 | TestFlight 4.0.0 (1033) | TestFlightの「開く」表示・実ファイルのバージョン照合、ホームの既存記録表示確認 |

iPhone・iPad用はXcode 27.2 beta 2でReleaseアーカイブを作成し、登録端末向けの配布署名でエクスポートした。署名後のCloudKit環境がProduction、get-task-allowがfalseであることを検証した。既定のXcodeは変更していない。Watch版・共有拡張も4.0.0 (1033)で同梱している。

Watch実機はDevice Hub/devicectlの接続一覧に現れず、Watch本体へのインストール・起動は直接確認できていない。同梱版の更新とWatch本体の更新確認は区別する。

Windowsでは初回の無人インストールが、起動中の旧版によるclrjit.dllの使用で終了コード5になった。旧プロセスを終了して再実行した後は成功した。ユーザーのデスクトップで起動するために使った一時タスクは解除済み。Macは旧版アプリのZIPをローカルに保存してから入れ替え、旧版の一時.appは削除した。

更新後、両PCの収集ログでは09:00 JSTまでの自動収集休止を確認した。これは既存の収集時間制御であり、今回の確認で実ファイルの転送成功を新たに主張するものではない。現在値機能の設定は変更せず、初期状態オフのまま利用者が選べる。

## 全項目表示の追加更新

- Mac 0.2.15 (18)：公証済みDMGから更新し、署名・公証チケットを検証。旧アプリのファイル上書きがOSに拒否されたため、旧バンドルをゴミ箱へ退避して新バンドルを配置した。更新後のプロセス起動を確認。
- Windows 0.1.12：旧プロセスを終了し、インストーラー終了コード0、ファイルバージョン0.1.12.0、ユーザーのデスクトップセッションでの起動を確認。一時起動タスクは解除した。
- iPad：Release・Production CloudKitの4.0.0 (1034)をインストール済み。ロック中のため更新後の起動・画面操作は未確認。
- iPhone：モバイル通信中で開発用接続が使用不可のため、1033からの実機更新は未実施。
- Mac上のiPhone/iPad版：TestFlight 1033のまま。1034への更新と閲覧専用表示の実機確認は残る。
- Watch：1034を同梱しているが、本体への更新は未確認。

TestFlight 4.0.0 (1034)は英語・日本語の説明を登録し、既存の内部・外部テスト配布処理を完了。外部テスト状態はIN_BETA_TESTING。Mac 0.2.15とWindows 0.1.12はGitHub Releaseに公開済み。Macの署名付き更新フィードはCI生成物と公開ファイルが一致する。Webのガイド・プライバシー説明も更新した。

詳しい検証範囲と未確認事項は[全項目検証メモ](LIVE_BATTERY_VERIFICATION_2026-10-08.md)に記載する。
