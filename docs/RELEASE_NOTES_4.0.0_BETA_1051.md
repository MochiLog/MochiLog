# MochiLog 4.0.0 beta (1051)

## 日本語

iPhone・iPadの動作ログを「設定 → デバッグ → 動作ログ」に集約しました。端末内取得、PC連携、転送、バックグラウンド動作を日付ごとに確認できます。受信したMac・Windowsのログ、保存日数、ストレージ整理も同じ画面にまとめました。PC連携や端末内取得をオフにしていても保存済みログを確認できます。

iPadでは設定の右側の画面内で一覧と保存設定を開きます。既存の解析エラーログは同じデバッグ欄に残しています。表示と説明は8言語に対応しています。

## English

Activity logs on iPhone and iPad are now grouped under Settings → Debug → Activity logs. View on-device collection, PC connections, transfers, and background activity by date. Received Mac and Windows logs, retention settings, and storage cleanup are in the same place. Saved logs remain available when either collection method is disabled.

On iPad, the list and storage settings stay in the settings detail pane. Existing parser error logs remain in the Debug section. Labels and descriptions support all eight languages.
