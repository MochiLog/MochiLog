# コード整形

Swiftは既存の `.swift-format` を基に2スペース・100桁で整形し、PythonはRuff 0.14.0を使用します。整形コマンドではSwiftの宣言・式を書き換えるルールを無効にします。単独でlintする場合の既存のルールは変更しません。

必要な開発ツールは `swift-format`、Python 3.10以降、`uv` です。アプリ利用者には追加ツールは不要です。

```sh
python3 scripts/format-code.py
python3 scripts/format-code.py --check
```

対象はGitが管理するソースと除外されていない新規ソースです。ビルド生成物、依存ライブラリ、診断データはGitの除外設定に従います。

## 2026-10-19の確認

Swiftの構文を整形前後で比較（配列・辞書の任意の末尾カンマは除外）。取り込み、8言語、Watch互換、CloudKitエラー、個体ID、受信ファイル、ペアリング、複数端末、現在値比較、バッチ解析、複数削除など13本の既存テストスクリプトが成功。iPhone向けビルド・実機へのインストール・起動と起動後のプロセス継続を確認。
