This build fixes a crash shortly after launching the iPhone/iPad version of MochiLog on a Mac. Donation product names and descriptions now follow the language selected in the app. iCloud diagnostics can compare local and iCloud record counts without changing records.

The 4.0.0 beta adds computer transfer for iOS/iPadOS 27. Install MochiLog Mac on macOS 27 or MochiLog Windows on Windows 11 from GitHub Releases. For first-time setup, unlock your iPhone or iPad, connect it once by USB, approve “Trust This Computer,” then scan the QR code shown on the computer in MochiLog → Settings → Advanced Settings → Mac Transfer. You can skip USB if the computer already has a working wireless OS pairing. MochiLog still works on the device by itself when computer transfer is not set up.

The computer collects analytics files from an unlocked iPhone or iPad, including eligible Apple Watch files stored on a paired iPhone. It temporarily queues the files and sends them through an encrypted connection when MochiLog opens. Parsing and recording stay on the mobile device. You can pair more than one Mac or Windows PC. Before sending a file, the computer uses an authenticated, encrypted digest inquiry to check whether it was already received through another computer or iCloud. Both sides confirm receipt before the computer clears its queue.

This build improves retries and complete parsing for Apple Watch logs. A failed import resumes computer collection; automatic communication slows once the required daily device and Watch logs have been received. Connection events, digest checks, and transfer outcomes can be inspected by date. When contacting support, you can choose an incident date and review the mobile and computer diagnostic logs from that date and the preceding two days before attaching them. We also improved reconnection after network changes and switching between paired computers. New records include a physical-device ID that survives export, import, and iCloud sync.

If Windows reserves the usual transfer port, MochiLog Windows 0.1.7 or later selects an available port. The mobile app now remembers the newly advertised port so existing pairings can reconnect.

Other fixes address a possible crash when sharing a chart from record Details, a registered Apple Watch record repeatedly appearing under manual import, and Analysis charts for localized device names. If exact duplicate records exist, Advanced Settings lets you review them before cleanup. The app backs up records first and preserves one copy across iCloud-connected devices.

Please test first-time pairing, iPhone/iPad and Apple Watch log receipt, duplicate prevention across resends and multiple computers, automatic reconnection after Wi-Fi changes, and the dated debug log viewer. New analytics collection requires the device to be unlocked and its diagnostic service reachable on a local wireless network. Cellular plus Tailscale can transfer files already collected by the computer, but cannot collect new system analytics. Computer transfer is unavailable on iOS/iPadOS 16–26; other MochiLog features remain available. This beta may take time to fix, and individual support replies may not always be possible.
