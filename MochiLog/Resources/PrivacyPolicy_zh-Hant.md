# MochiLog 隱私權政策

## 1. 處理的資料

MochiLog在裝置上處理使用者選擇的iPhone、iPad及Apple Watch分析日誌，並儲存電池記錄、機型、日期、容量、產品地區和用來區分實體裝置的識別碼。原始日誌可能包含其他裝置及使用資訊。設定與記錄通常保存在使用者裝置上，不會自動傳送給開發者。

## 2. 選用的同步與傳輸

開啟iCloud同步後，記錄透過使用者的iCloud私人資料庫在同一Apple帳號的裝置間同步。記錄也可傳至配對的Apple Watch，或由使用者匯出、分享。在適用於iOS/iPadOS 27和macOS 27的Mac傳輸測試版中，已配對Mac僅於行動裝置解鎖時收集日誌、暫存，並在同一區域網路加密傳送給MochiLog。雙方交換配對資訊、傳輸狀態及診斷資訊。日誌不會送至開發者伺服器。Mac應用程式會連接GitHub檢查更新；GitHub可能收到IP位址等網路資訊。 Windows 11配套應用程式的Alpha版也會將已配對PC上的日誌加密傳送至MochiLog。

啟用即時電池後，已配對的電腦會從裝置診斷服務讀取目前的充電循環與容量等數值，並加密傳送至手機應用程式。這些目前值僅保留在記憶體中，不儲存到歷史、電池記錄、iCloud或支援診斷日誌。此設定預設關閉。此處理與每日Analytics檔案的收集和保管相互獨立。使用使用者自行設定的Tailscale等VPN通訊時，也適用該服務的條款與資料處理方式。

## 3. 支援請求

使用者傳送支援郵件時，開發者會收到暱稱、電子郵件、內文及附件。Mac傳輸支援在使用者傳送時附上系統和應用程式版本、機型、傳輸狀態、裝置識別碼、錯誤及近期診斷事件。事件可能包含檔名或路徑，請在寄出前檢查。郵件服務商也會處理郵件。資訊會於處理請求和保留必要紀錄期間保存；除法律要求保留外，可要求刪除。

## 4. 儲存與刪除

可用應用程式內的刪除功能移除本機記錄。關閉iCloud同步不會自動刪除已在iCloud或其他裝置上的記錄。Mac的待傳日誌和配對資訊存在Application Support中，僅刪除應用程式本體仍可能保留。需要刪除協助請聯絡支援。備份和重新安裝會影響可還原的資料。 預設情況下，Mac和Windows應用程式在行動裝置確認接收後立即刪除原始日誌。若啟用保留，已確認的日誌預設最多保存500MB、一個月（均可調整），並可匯出、手動重傳或刪除。未確認的待傳日誌不會自動清理，也無法手動刪除。

## 5. 外部服務與變更

MochiLog不使用廣告、追蹤或第三方使用情況分析SDK。App Store版的自願贊助使用Apple StoreKit。網站由Cloudflare提供，瀏覽時可能處理IP位址等網路資訊。政策變更會在網站及應用程式內文件註明更新日期。

PC 日誌分享僅在雙方均與同一電腦配對、開啟 iCloud 同步並確認使用同一 Apple 帳號時，才加密傳輸其他裝置的日誌。使用 App 專屬 CloudKit 使用者 ID 的雜湊值比對，不向電腦傳送 Apple ID、信箱或原始使用者 ID。此雜湊值用於帳號比對，不保證匿名性。授權暫存於電腦記憶體，關閉同步或變更帳號時撤銷。若裝置無法通訊，原授權可能最多保留 15 分鐘。保留來源裝置 ID，日誌不傳送至開發者伺服器。

可選的裝置內取得透過本機VPN或反射器路徑驗證並連接本裝置診斷服務。系統配對憑證保存在裝置專用鑰匙圈中，使用者可明確選擇透過已驗證的PC加密連線繼承，或匯入檔案。金鑰及分析日誌不會傳送至開發者伺服器。匯入成功後刪除暫存檔案。同一PC上其他裝置的目前值僅在雙方皆已確認開啟iCloud同步且使用相同Apple帳號時共享；值本身不儲存至歷史、iCloud或診斷日誌。PC自動檢查更新預設關閉，啟用後連接GitHub。所用VPN服務的資料政策同樣適用。

iOS/iPadOS 27及以上版本可在設定中明確授權後，在App內建立本裝置的系統配對憑證，無需從電腦匯入檔案。驗證碼僅在配對期間顯示於App、系統工作和已授權的通知中，不記錄到診斷日誌或支援附件。取消或完成後停止通知及監聽。憑證保存在本裝置專用鑰匙圈中，不傳送給其他裝置或開發者伺服器。
